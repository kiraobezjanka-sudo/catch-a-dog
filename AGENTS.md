# «Поймай таксу» — правила проекта

Этот файл является главным оглавлением и набором обязательных инструкций для дальнейшей работы над игрой.

## Основные инструкции

- Работать только с файлами внутри текущей папки проекта.
- Считать игру самостоятельным проектом. Не переносить из других игр код, дизайн, ресурсы или игровую механику.
- Использовать старые проекты только как пример организации документации, тестов, Git-процесса и публикации.
- Первая версия предназначена для ПК и должна оставаться простой.
- Не добавлять сторонние JavaScript- или CSS-библиотеки без прямой необходимости и согласования.
- Сохранять обязательные правила: раунд 30 секунд, такса меняет место только после успешного клика, `Escape` ставит игру на паузу и продолжает её, лучший результат сохраняется в текущем браузере.
- Отделять игровую логику от интерфейса, чтобы основные состояния проверялись автоматическими тестами.
- После изменения логики запускать автоматические тесты.
- После визуальных или интерактивных изменений проверять игру в настольном браузере.
- Перед публикацией выполнять сборку и не публиковать версию с ошибками.
- Работать в отдельной ветке `codex/*`, передавать изменения через Pull Request и прикладывать ссылку-превью.
- Не сохранять ключи, пароли, токены или другие секреты в файлах проекта и истории Git.
- При изменении поведения обновлять тематическую документацию и корневой `CHANGELOG.md`.

## Порядок работы

1. Прочитать `AGENTS.md` и связанные с задачей документы.
2. Внести минимально необходимое изменение в ветке `codex/*`.
3. Одновременно обновить документацию и `CHANGELOG.md`, если изменилось поведение.
4. Запустить тесты и сборку.
5. Проверить затронутый сценарий в настольном браузере.
6. Создать или обновить Pull Request и проверить его ссылку-превью.
