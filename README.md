# Поймай таксу

Простая веб-игра на реакцию для ПК. За 30 секунд нажмите на мультяшную таксу как можно больше раз и установите локальный рекорд.

## Как играть

- Нажмите «Начать игру».
- Каждый клик по таксе приносит одно очко и перемещает её в новое место.
- Раунд длится 30 секунд.
- Нажмите `Escape`, чтобы поставить игру на паузу или продолжить.
- Лучший результат сохраняется локально в браузере.
