# Сборка, Pull Request и публикация

Изменения выполняются в ветке `codex/*` и передаются через Pull Request в `main`.

Перед Pull Request необходимо запустить автоматические тесты и сборку. GitHub Actions собирает ветку Pull Request и публикует её как проверочную версию GitHub Pages. Ссылка на неё добавляется в Pull Request. После слияния основная версия публикуется из `main`.

В конфигурации и истории Git запрещено хранить секреты и временные данные авторизации.
