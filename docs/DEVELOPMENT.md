# Разработка и тестирование

Проект не требует сторонних библиотек. Игровая логика находится в `game-core.js`, интерфейс — в `game.js`, оформление — в `styles.css`.

Обязательные проверки:

- тесты подтверждают старт, начисление очков, завершение, паузу, продолжение и перезапуск;
- сборка должна создавать клиентские файлы и обработчик сайта;
- в браузере проверяются старт, клики, перемещение только после клика, `Escape`, завершение и сохранение рекорда после перезагрузки.
