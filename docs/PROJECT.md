# Описание проекта

«Поймай таксу» — короткая настольная веб-игра на реакцию. Игрок за 30 секунд старается как можно больше раз нажать на мультяшную таксу.

## Первая версия

- один игровой экран;
- управление мышью и клавишей `Escape`;
- один локальный лучший результат;
- без регистрации, общей таблицы лидеров, уровней, звуков и мобильного режима.

Проект не использует дизайн, ресурсы или механику предыдущих игр.
