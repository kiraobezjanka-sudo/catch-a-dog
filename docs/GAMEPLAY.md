# Правила игры и управление

1. Игрок нажимает «Начать игру».
2. Запускается таймер на 30 секунд.
3. Клик по таксе добавляет одно очко и переносит её в случайное допустимое место поля.
4. Без успешного клика такса остаётся на месте.
5. `Escape` останавливает таймер и блокирует начисление очков. Повторный `Escape` продолжает игру.
6. При нуле секунд раунд завершается, а лучший результат сохраняется в текущем браузере.
