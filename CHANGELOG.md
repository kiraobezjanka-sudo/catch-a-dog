# История изменений

## В разработке

### Изменено

- GitHub Actions обновлены до стабильных версий: `checkout 7.0.1`, `setup-node 7.0.0`, `pr-preview-action 1.8.1` и `github-pages-deploy-action 4.9.0`.
- Визуальный стиль переведён на тёмную ночную тему: тёмный интерфейс, луна и звёзды на игровом поле.

### Добавлено

- README дополнен правилами игры и ссылкой на проверочное превью Pull Request.
- Первая версия игры «Поймай таксу» для ПК: 30-секундный раунд, начисление очков, перемещение таксы после клика, пауза по `Escape` и локальное сохранение рекорда.
- Самостоятельный визуальный стиль и новая мультяшная такса.
- Автоматические тесты игровой логики, сборка, документация и правила дальнейшей работы.
- Автоматическая публикация отдельного превью каждого Pull Request в `/pr-preview/pr-<номер>/`, его обновление и очистка после закрытия.
- Публикация `main` сохраняет активные PR-превью в ветке `gh-pages`.
- Карточка публикации подключена через Open Graph и Twitter metadata.
